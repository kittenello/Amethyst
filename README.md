# Installation / How to run

**For normal users, you only need setup.exe.**

```⚠️ PREREQUISITE: You MUST have Python installed on your computer before running the setup. Download and install Python 3.11.9 (make sure to check "Add Python to PATH" during installation) from python.org```

1. Download or clone this repository.
2. Open the project folder.
3. Run setup.exe.
4. Wait until setup finishes.
5. Start your Android emulator.
6. Open Brawl Stars in the emulator.
7. Set the emulator resolution to 1920x1080 for best results.
8. Run generated file "run.bat"

# Discord / Telegram remote control :

**Open cfg/discord_config.toml or cfg/telegram_config.toml.**

For Discord, Webhook notifications only need webhook_url. For interactive commands, provide a bot token.

Keep tokens private. Anyone with it can control the bot.

Fill in your user_id so the bot only listens to you.

In Discord/Telegram, use the interactive UI buttons or type commands like /start, /stop, /status, /queue, and /screenshot.

Restart Amethyst after changing remote-control settings.
